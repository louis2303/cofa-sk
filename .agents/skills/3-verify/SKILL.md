# 3. 독립 검증 및 최종 점검

## 목적
AI가 완료했다고 말한 결과가 **실제로 작동하고 과제 요구사항을 충족하는지** 확인한다.

## 절차
1. 최초 과제 지시사항, 확정 요구사항, 필수 결과물·제출 조건을 다시 읽는다.
2. 결과물을 실제 파일·코드·원본 데이터와 대조한다. 이전 AI의 '완료' 보고만 근거로 삼지 않는다.
3. 과제 유형에 맞는 테스트를 직접 실행한다.
   - 웹/프로그램: 주요 기능, 입력 오류, 경계값, 가능하면 회귀 테스트
   - 데이터/계산: 원자료, 계산식, 경계 조건, 독립 재계산
   - 문서/보고서: 필수 항목, 출처, 수치, 형식, 누락
   - Agent: 공통 규칙, Skill 선택, Tool 실행, 기억 저장·재조회, 자동화 실행기록, 승인 동작 중 요구된 항목
4. 검증 결과를 **충족 / 미충족 / 확인 필요**로 나누고 각 항목에 실제 근거를 붙인다.
5. 오류가 확인되면 원인을 분석해 최소 범위로 수정한 다음 같은 조건에서 재검증한다.
6. 기존 정상 기능에 영향이 없는지 확인하고, 제출에 필요한 경로·파일·저장 상태를 점검한다.
7. 중요한 검증 결과와 남은 한계는 간결하게 보고하고 필요하면 work_log.md에 추가한다.

## 출력
- 요구사항별 상태와 검증 근거
- 실제 실행한 테스트 및 성공/실패 결과
- 미검증·미완료 사항
- 제출 전 우선 수정할 문제

## 주의
- 실행하지 않은 테스트는 '통과'라고 적지 않는다.
- 외부 도구·Browser 접근이 막히면 우회하지 말고 그 한계를 알린다.
- 제출 확정이나 후속 서술형을 사용자 대신 수행하지 않는다.
